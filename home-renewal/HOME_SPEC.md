## 1. 경쟁사 분석 (스크린샷 기준)

| | Pinxai | BabeChat | 우리 현재 (`HomeC`) |
|---|---|---|---|
| 상단 | 와이드 배너 1장 + 화살표, 아래에 공지 한 줄 | 3장 엿보이는 캐러셀 (가운데 크게) | 배너 없음. "오늘은 뭐 할까요?" 큰 카드 3개 + 띠 배너 5~6개를 세로로 쌓음 |
| 탭 | ホーム/新作/ランキング/タグ (가운데 정렬 알약 탭) | ホーム/新着ランキング/ランキング/刺激的/カテゴリー/タグ/ベイビーズ (글자 탭, 7개) | 없음 (`/chat` 은 따로 카테고리 메뉴) |
| 카드 | 1:1 정사각, N 배지, ♡·채팅 수, 제목, 2줄 설명, 태그 3개, 크리에이터 | 1:1 정사각, B ONLY 배지, 채팅 수, N, 제목, 2줄 설명, 태그, 크리에이터 | 3:4, 순위 숫자, 채팅 수, 이름, 1줄 소개. **태그·크리에이터·좋아요·N 없음** |
| 랭킹 | 1위~ 큰 숫자 + 5열 그리드, 일간 선택 | 즉시·일간·주간·월간, 정렬 2종, 기준 시각 표시 | 홈 "인기" 레일 12개뿐, 기간 선택 없음 |
| 태그 | 가로 칩 + 태그 일람 | 카테고리·태그 탭 | `/chat?tag=` 는 되지만 홈에 노출 없음 |
| 상세 | 모달: 큰 이미지, 크리에이터·팔로우, 1줄 소개, はじめる | 모달 | 바로 채팅방으로 이동 |
| 만들기(UGC) | 좌측 "作成する" 버튼뿐 | 좌측 "キャラクターを作成"뿐 | 기능은 가장 많음 (이미지·망가·영상·애니). 그런데 홈에서 띠 배너로 흩어져 있음 |

**경쟁사의 약점 (우리가 이길 지점)**
1. 카드가 전부 같은 크기에 같은 정보라서, 레일이 계속 반복되면 지루해.
2. 랭킹에 순위 변동(▲▼)·기준이 없어. BabeChat만 기준 시각을 표시해.
3. 상세 모달에 "첫 대사"나 목소리 샘플이 없어서, 들어가기 전엔 대화 톤을 알 수 없어.
4. 만들기 기능은 메뉴 버튼 하나뿐이고, 유저 작품 갤러리나 크리에이터 보상 노출이 약해. Pinxai는 배너로만 "クレジット"를 소개해.
5. BabeChat 탭은 7개라 너무 많아. Pinxai 4탭 구조가 더 쉬워.

## 4. 캐릭터 홈 (`Characters.dc.html`, 모바일 `CharactersMobile.dc.html`)

**상단 고정 헤더:** 제목 "캐릭터", 검색창(이름·태그·상황 통합 검색), "+ 캐릭터 만들기" 버튼, 알약형 탭 4개(홈/신작/랭킹/태그). 스크롤해도 탭은 화면 위에 붙어 있어.

**① 홈 탭**
1. 콘테스트 한 줄 띠 (메인 홈 배너보다 작게)
2. 지금 인기 태그 9개 + 개수 → 누르면 태그 탭으로 이동
3. 당신을 위한 추천: 6열 × 2줄 = 12장, "새로 고침" 버튼
4. 오늘의 랭킹 가로 레일 10장 → 랭킹 탭
5. 24시간 안에 나온 신작 가로 레일 → 신작 탭
6. 테마 레일 3~6개, §8 순서: アイドル×ギャップ萌え / ハーレム / NTR / 幼なじみ·ツンデレ / 現代日常 / 純愛×ギャップ

**② 신작 탭:** 기간 칩 24시간·3일·1주, 정렬 "대화가 빨리 느는 순"(기본)·최신순. 6열 무한 스크롤.

**③ 랭킹 탭**
- 종류 칩: 전체 / 1:1 / NTR / 그룹 / 스토리.
- 기간: 일간·주간·월간.
- 기준 문구: "11.14 12:00 기준 · 대화 수 70% + 좋아요 30% · 1시간마다 갱신".
- **1~3위는 큰 가로 카드**(이미지 + 큰 순위 + 설명 3줄 + 대화·좋아요 수), 4위부터는 6열 카드에 순위 숫자와 ▲▼/NEW 표시.

**④ 태그 탭**
- 태그를 4개 그룹(관계 / 속성 / 상황 / 장르)으로 묶어 보여주고, 각 태그 옆에 개수를 표시해.
- 하나를 고르면 아래에 "#태그 캐릭터" 그리드가 나와. 여러 태그 동시 선택(AND)은 P1.

## 7. 정렬·랭킹·개인화 로직

| 목록 | 로직 |
|---|---|
| 랭킹 점수 | `score = 0.7 × 정규화(기간 내 메시지 수) + 0.3 × 정규화(기간 내 좋아요)`. 일간=최근 24h, 주간=7일, 월간=30일. 1시간마다 계산해서 캐시. 순위 변동 = 직전 집계 대비 |

| 공통 제외 | 차단·신고 누적 캐릭터, 이미지 검수 미통과 캐릭터 |

## 8. 태그 전략

- **인기 태그 (노출 순서):** #アイドル #ハーレム #NTR #ギャップ萌え #ツンデレ #幼なじみ #現代 #巨乳 #純愛
- **테마 우선순위:**
  1. アイドル/プロデューサー × ギャップ萌え
  2. ハーレム (셰어하우스·대학 기숙사)
  3. NTR
  4. 幼なじみ ツンデレ
  5. 現代日常 (편의점·방송인·직장)
  6. 純愛 × ギャップ
- **태그 정리:**
  - 일본어 표기 하나로 통일하고, 한국어·영어는 표시용 번역만 둬. 예: 幼馴染/幼なじみ → `幼なじみ`.
  - 캐릭터를 만들 때 태그는 1~5개를 필수로 받아. 추천 태그 칩을 보여줘.
- **태그 그룹 (태그 탭):**
  - 관계(幼なじみ·先輩·上司·同居·秘密の関係)
  - 속성(ツンデレ·ギャップ萌え·巨乳·眼鏡·年上)
  - 상황(NTR·ハーレム·背徳·ラブコメ·甘々)
  - 장르(アイドル·現代·配信者·大学·純愛)
- **나이 규칙:** 교복·학생·학원 설정 태그는 노출하지 마. "학원 하렘"은 **대학·기숙사·셰어하우스**로 대체해. 모든 캐릭터는 20세 이상이야 (기존 studio 규칙과 동일).

## 11. 기존 코드에서 고칠 곳

1. **`pages/home.js` `slimChar`** 가 `assistantId·이름·소개·이미지·messageCnt` 만 남기고 버려. 카드에 필요한 `likeCount`, `tags`, `createUserName`, `createUserProfileImg`, `createdAt`, `type`(1:1/NTR/그룹/스토리), `openingMessage`, `hasVoice` 를 남겨. (§13: 서버 응답에 이 필드가 있는지 먼저 확인)
2. **`getServerSideProps`** 는 Top/New 12개씩만 받아. 홈 섹션별로 쿼리를 나누고 클라이언트에서 지연 로딩해서 첫 화면을 가볍게 해. 서버에서는 배너·이어하기·추천 6개·랭킹 10개만 받아.
3. **`HomeC`** 는 hero 변형 3개 × skin 3개 + 변형 a~d 가 공존해서 1,662줄이야. 새 `MainHome` 하나로 정리하고, 실험은 `?home=` 쿼리 대신 Mixpanel 기능 플래그로 해.
4. **세로로 쌓인 띠 배너들** (`HomeBonusBanner`, `promoBanner`, `StoryHomeBanner`, `MangaBanner`, `WelcomeHomeCard`, `SceneHomePromo`, `InstallMiniBanner`) → `HeroCarousel` 슬라이드로 합치고, 홈에는 공지 한 줄만 남겨.
5. **`CharCard`:** `CardImg` 비율 3:4 는 유지해. `Count` 는 좋아요+대화 알약으로 바꾸고, 태그·크리에이터 줄을 추가해. `Rank` 는 이미지 아래 큰 숫자 + 변동 표시로 바꿔.
6. **`/chat` (`Discover_v2`)** 의 카테고리 메뉴(`/v4/message/menu`)는 상단 탭 4개 + 태그 탭으로 정리해. 기존 `category`·`tag`·`style` 쿼리는 그대로 받아서 하위 호환을 지켜.
7. **랭킹 API:** 지금은 `category=Top` 하나야. `period=day|week|month`, `type=all|chat|ntr|group|story`, 응답에 `rank`·`prevRank` 를 추가해야 해 (서버 작업).
8. **태그 API** `/v4.0.1/assistant/tag/category` 로 태그 그룹·개수를 받아. 개수 필드가 없으면 추가해.
9. **카드 노출 트래킹:** 기존 `useCardImpression` 을 새 카드에도 그대로 써. `surface` 값을 정리해: `home_rec`, `home_rank`, `home_theme_*`, `chars_rec`, `chars_rank`, `chars_new`, `chars_tag`, `detail`.

## 12. 경쟁사보다 나아진 점

1. **카드 정보량은 같고 인물은 더 크게:** 3:4 이미지에 태그·크리에이터·좋아요·대화 수를 다 넣었어.
2. **들어가기 전에 대화 톤 확인:** 마우스 올림 첫 대사, 상세 모달 목소리 샘플. 경쟁사엔 없는 기능이야.
3. **랭킹 신뢰도:** 기준 시각·산식 표시, ▲▼ 변동, 1~3위 포디움, 종류·기간 필터.
4. **배너 정리:** 세로 띠 6~7개 → 캐러셀 1개 + 공지 한 줄. 첫 화면에 캐릭터가 더 빨리 보여.
5. **만들기가 주인공 중 하나:** 메인 홈 2~3번째 섹션에 결과물 이미지가 들어간 4타일. 경쟁사는 버튼 하나뿐이야.
6. **UGC → 재제작 루프:** 작품마다 "이 캐릭터로 만들기" 버튼이 있어서, 보는 사람이 만드는 사람이 돼.
7. **크리에이터 동기:** 콘테스트 + 주간 크리에이터 TOP5 + 적립 pt를 메인에 상시 노출해.
8. **모바일 하단 탭 가운데 "만들기":** 어느 화면에서든 한 번에 제작으로 갈 수 있어.

## 16. v1.2 추가 (2026-11-14)

### 16.1 이어서 대화하기 — 안 읽은 메시지 강조
- 안 읽은 방의 시간 옆에 **핑크 점이 퍼지는 애니메이션**(1.4초 반복)을 넣어. 섹션 제목 "새 메시지 N" 앞에도 같은 점을 둬.
- `prefers-reduced-motion` 이면 애니메이션을 끄고 점만 보여줘.
- 칸 순서 (데스크톱 4칸):
  1. 최애 찾으러 가기 (`/chat`)
  2. 안 읽은 방 (최신순)
  3. **아까 본 캐릭터의 첫 메시지** (§16.2)
  4. 나머지 최근 방
- 안 읽은 방이 없으면 최근 방으로 채워. 모바일은 동그란 아바타 줄에 같은 점과 노란 링을 써.

### 16.2 신규 기능: "아까 본 캐릭터가 먼저 말 걸기"
- **조건:**
  - 로그인 유저가 캐릭터 소개 팝업을 **8초 이상** 봤거나 갤러리를 넘겨봤어.
  - 그런데 **10분 안에 대화를 시작하지 않았어.**
- **동작:** 그 캐릭터가 첫 메시지를 보내. 문구는 "프로필을 봤다"는 걸 아는 1~2문장이야. 예: 「さっき、私のプロフィール見てたでしょ？…声、かけてくれないの？」
- **구현:** 기존 웹 선톡 인프라를 재사용해 (선톡 수신 동의, 발송 기록, 비용 없음). 새 트리거 종류 `profile_view` 를 추가해.
- **제한:**
  - 유저당 하루 1회, 같은 캐릭터는 7일에 1회.
  - 선톡을 끈 유저와 차단한 캐릭터는 제외해.
  - 메시지는 무료이고, 답장부터 보통 과금이야.
- **표시:**
  - 이어서 대화하기에 **노란 테두리 + "아까 본 캐릭터 · 첫 메시지" 배지 + 노랑→핑크 아바타 링**으로 보여줘.
  - 내 채팅 목록과 알림벨에도 같은 배지를 달아.
- **측정:** `profile_view_dm_sent`, `profile_view_dm_open`, `profile_view_dm_reply` (답장률이 핵심 지표).
- **필요한 이벤트:** 소개 팝업 `character_detail_view {assistantId, dwellMs, galleryViewed}`. 서버에 기록해서 트리거 판단에 써.

### 16.3 기능 아이콘 통일 (학습용)
같은 기능은 어디서나 **같은 아이콘 + 같은 색 사각 배지**로 보여줘. lucide 아이콘을 기준으로 해.

| 기능 | 아이콘 | 색 |
|---|---|---|
| 이미지 | `Image` | `#f59e0b` |
| AI 미니 망가 | `BookOpen` | `#3b82f6` |
| 영상 | `Video` | `#ff3d7f` |

### 17.5 랭킹 페이지를 시안과 같게

- **시상대 카드**: 이미지 아래를 카드 색으로 그라데이션 처리하고, 제목·훅이 이미지 위로 40px 겹치게 올라와. 왼쪽 위에 동그란 순위 배지(금·은·동 색) + 변동(▲▼) 알약.
