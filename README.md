# animaka-design-assets

fan.stipop.ai 신규 기능 **Animaka**(유저가 만드는 AI 애니)의 기획·디자인 자료.

- `docs/ANIMAKA_SPEC.md` — 개발 기획서 (여기서 시작)
- `design/*.dc.html` — 화면 시안 원본 (인라인 스타일이 정확한 수치). 이미지는 `../images/` 를 가리킨다
- `design/tokens.json`, `design/design-system.md` — Stipop FANZA 디자인 토큰 (fan.stipop.ai@95e6189 에서 추출)
- `images/` — 시안·샘플용 생성 이미지 (모든 인물은 성인, 비노출)
- `home/` — 홈 화면 시안용 이미지 (캐릭터 카드 c01–c10, 배너 b01–b04, 유저 제작 예시 u01–u06)
