## 1. 왜 바꾸나
지금은 항목 21개, 배지 7종이 한꺼번에 보인다.
- 신규 35%는 메시지를 한 번도 안 보낸다.
- 매출 43%인 영상은 맨 아래 하위 메뉴에 있다.
- 혜택·도움말·리뷰 입구가 없다.

## 3. 상태별 규칙
| 상태 | 판정 | 맨 위 카드 | 구역 순서 |
|---|---|---|---|
| 신규·미결제 | DMM 결제 0 | はじめてガイド n/5 (+50pt) | はなす(전체) → つくる(2개만, 나머지 접힘) → わたし |
| 결제자 | 결제 1+ | 안 써 본 고매출 기능 1개 (영상 → 씬 이미지 → 망가), 지금 대화 중인 캐릭터로 | はなす → つくる → わたし |
| 제작자 | 공개 캐릭터 1+ | 내 캐릭터 오늘 성과 + TOP10까지 남은 대화 | わたし → つくる → はなす |
| 헤비 | S7 | VIP 先行公開 (TEST 기능 먼저 열기) / 3일 미접속 시 おかえり | よく使う(핀 3) → はなす → つくる → わたし |

- 상태가 겹치면 헤비 > 제작자 > 결제자 순으로 판정한다.
- API: `/home14/me/creator-state`를 확장해 `navState`와 `slotCard`를 내려준다.

## 4. 배지 규칙
- 한 번에 최대 3개까지 보여준다. 카운트 배지는 개수에서 뺀다.
- 「NEW」는 출시 후 14일만 붙인다.
- 「初回50%」·「+120pt」는 첫 사용 전까지만 붙인다.
- 「未体験」은 안 써 본 기능 중 1개에만 붙인다. 30일 매출 기여가 큰 순서로 고른다.
- 맨 위 카드를 X로 닫으면 24시간 동안 다음 후보 카드를 보여준다.

## 5. TEST ONLY
- 플래그 `nav.testOnly`가 true인 항목은 테스트 서버(또는 헤비 VIP 선공개 대상)에서만 렌더한다.
- 이 항목에는 노란 점선 「TEST ONLY」 태그를 붙인다.
- 대상: 制作スタジオ(/studio) · スマートクリエイター · キャラクターブック(/characterbook) · キャラ作成(新モード)(/create)
- 라이브로 전환할 때는 플래그만 끄면 같은 자리에 그대로 나온다.

## 6. 모바일 (B 최종)
- **하단탭이 보이는 곳:** ホーム·さがす·裏フィード·マイチャット 목록·特典처럼 둘러보는 화면.
  - 대화방(1:1·NTR·그룹), 제작 화면(동영상·Animaka·캐릭터 만들기), 결제·시트에서는 숨긴다.
  - 아래로 스크롤하면 숨고, 위로 올리면 다시 보인다.
- **＋つくる 버튼:** 다른 탭과 같은 줄·같은 높이(아이콘 32px + 라벨)로 둔다. 바 위로 튀어나오지 않게 한다.
- **＋ 시트:**
  - 맨 위에 상태별 추천 1장.
  - メディア 4개(동영상·이미지·망가·애니) / キャラ 3개(캐릭터·리메이크·마이미디어) / ラボ 3개(TEST ONLY).
  - 배지는 오른쪽 위 알약 1개만 붙인다. 아이콘은 그라데이션 타일 + 흰 그림 2톤 SVG(`design/MSheet.dc.html`)를 쓴다.
- **대화방 상단바:** ← · 아바타 · 이름 · 상태 한 줄 · 버튼 최대 3개 · DMM pt 미니칩 · ⋯ (규칙표: `design/ChatRules.dc.html`)
  - NTR: 아바타 2개(그녀+그), 「いまの場面」 칩, 「ふたりの距離」 게이지, 証拠・記録 버튼.
  - 그룹: 아바타 3개 겹침, 멤버 추가 버튼. 입력란 위에 「話しかける相手」 칩.
- **대화방 입력란:** 답장 추천 칩 3개 → 입력란(음성 입력 포함) + 전송 → 맨 아래 한 줄(모델 선택 · 무료 남은 횟수 · 1회 비용).
  - NTR은 입력란 왼쪽에 「行動」 버튼을 둔다.
- **데스크톱 대화방:** 좌측바를 아이콘 레일(76px)로 접는다. 오른쪽에 프로필 + 추천 1장 패널을 둔다.

### 6-1. 모바일 기본
- **상단바:** ☰(받을 혜택이 있으면 빨간 점) · 화면 이름 · DMM pt 칩 · 알림.
- **하단탭:** ホーム · さがす · ＋つくる(시트) · 裏フィード · マイチャット.
- **☰ 메뉴:** 데스크톱 B와 같은 구조.
- **＋つくる 시트:** 상태별 추천 1줄 + 3열 타일. TEST ONLY 타일도 같은 자리에 넣는다.

## 7. 도움·커뮤니티 (`/help`)
1. **AIサポート**
   - 기존 채팅 LLM + 계정 조회 도구(포인트 내역, 생성 작업 상태, 결제 기록)를 쓴다. 읽기 전용이다.
   - 해결이 안 되면 「人に相談する」 → 기존 문의로 대화 기록을 넘긴다.
   - 환불·포인트 지급 같은 쓰기 작업은 하지 않는다.
2. **はじめてガイド**
   - 5단계: キャラ選択 → 5回会話 → こえ → ムードショット → 7日ボーナス. 각 +10pt, 합계 +50pt.
   - 단계는 데이터에서 이탈이 큰 구간에 맞췄다.
3. **ご意見・リクエスト**
   - 투표형 게시판. 상태는 受付 / 検討中 / 開発中 / 公開.
   - 채택되면 300pt를 준다.
4. **みんなの声**
   - 리뷰 요청 팝업(H2)으로 모은 실제 리뷰만 보여준다. 시안의 문구는 예시다.
   - 팝업이 뜨는 때: 첫 영상 완성, 30턴 대화, 미션 완료 같은 좋은 순간 직후. 30일에 1회까지.
   - 별 4~5개 → みんなの声 게시 동의. 별 1~3개 → AIサポート/ご意見으로 안내한다.
